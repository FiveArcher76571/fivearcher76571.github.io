# SAIEngine Semantics

This page will go over the core functionality of the engine, outlining how you can use it to make things!

## The Resources Folder

Everything that you create to run in SAIEngine lives in a folder titled `resources`. As mentioned in the home page, this folder **must be placed adjacent to the engine executable**. This folder can contain anything from assets (like images, audio files, etc.) to Lua scripts and everything in between. Basically, if it's not in `resources`, it's not getting read, and if it *is* in `resources`, chances are it's getting read.
