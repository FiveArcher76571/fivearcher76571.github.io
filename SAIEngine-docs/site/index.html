Welcome to SAIEngine!

This is the documentation for SAIEngine, where you can find an explanation of the general semantics for using the engine, as well as a full API reference.

Features

  • C++ backend with Lua scripting
  • Unity-like actor, component, and scene management
  • SDL3-powered rendering, audio, and input management
  • Fluidsynth-powered live synthesis/MIDI playback using SoundFonts
  • MIDI controller support for use as a synth controller or game input
  • Portable design - works on Windows, Mac, and Linux machines
  • ...and more!

How to Download/Use

  1. Download the latest release of SAIEngine for your platform here
    • If you'd like, you can also build the project yourself by visiting SAIEngine's GitHub repo
  2. Create a resources folder adjacent to the downloaded executable
    • This folder will contain all of your scenes, components, and assets
  3. Run the executable and watch your project come to life!

How to Navigate the Docs
